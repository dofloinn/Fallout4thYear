### <mark style="background: #C900FFA6;">History of React</mark> 

It was developed by a team at Facebook, led by Jordan Walke, in 2011.  

It was first used on the Facebook News Feed that same year. In May 2013, Facebook open-sourced it.  

Facebook released React Native, a framework for building native mobile applications, in 2015.  

React 16, a significant update to the library, was released in September 2017.  

React Hooks, a new method for managing state and side effects in React components, were introduced in February 2018. In November 2020,  

Facebook announced Concurrent Mode and React Server Components, two new features designed to enhance performance and rendering flexibility.

### <mark style="background: #C900FFA6;">What is React?</mark>

React is a JavaScript library for building user interfaces (UIs).  

It utilises a component-based approach to divide the UI into smaller, reusable components. A component is a piece of reusable UI that encapsulates its logic and state.  

React maintains a <mark style="background: #C900FFA6;">virtual representation</mark> of the DOM to update the real DOM efficiently.  

React is declarative, allowing you to describe the UI you wish to create in a straightforward manner. React supports server-side rendering, enhancing performance and enabling search engines to index your content.  

React is widely used, and a large, active community of developers is creating tools and libraries to support it.

### <mark style="background: #C900FFA6;">Advantages of React</mark> 

Component-based architecture makes it <mark style="background: #C900FFA6;">easier to build and maintain complex UIs</mark>.  

React's virtual DOM allows for efficient updates and improved performance.  

The declarative syntax makes code easier to understand and reason about.  

<mark style="background: #C900FFA6;">React is highly reusable</mark> and encourages code modularity.  

A large and active community provides a wealth of resources and support.  

<mark style="background: #C900FFA6;">Server-side rendering</mark> can improve performance and SEO.  

React Native allows for <mark style="background: #C900FFA6;">easy development of mobile apps</mark> using the same codebase.  

React is compatible with a wide range of tools and technologies.

React's one-way data binding simplifies state management.  

React provides a range of helpful debugging tools and resources.

### <mark style="background: #C900FFA6;">Disadvantages of React</mark> 

<mark style="background: #C900FFA6;">Steep learning curve:</mark> React has a relatively steep learning curve, particularly for developers new to the library or front-end development.  

<mark style="background: #C900FFA6;">Knowledge of other technologies is required:</mark> Developers generally need to be familiar with various technologies, such as JavaScript, HTML, and CSS, to use React effectively. 

<mark style="background: #C900FFA6;">Limited out-of-the-box functionality:</mark> React mainly serves as a library for building UI components and does not offer built-in functionality for other tasks, such as data fetching or routing.  

<mark style="background: #C900FFA6;">Large file sizes:</mark> Depending on its usage, React can result in larger file sizes and slower load times, negatively impacting performance-sensitive applications.  

<mark style="background: #C900FFA6;">Requires a build step:</mark> To implement React in a web application, developers usually need to establish a build step using tools like Webpack or Babel, adding complexity to the development process.  

<mark style="background: #C900FFA6;">Community fragmentation:</mark> With a large and active community, React offers many tools and approaches, which could potentially lead to fragmentation and confusion among developers

### <mark style="background: #C900FFA6;">History of Angular</mark> 

Google released AngularJS (1.x) in 2010 as an <mark style="background: #C900FFA6;">open-source JavaScript</mark> framework for building dynamic web applications.  

AngularJS gained popularity due to its two-way data binding and declarative programming model.  

<mark style="background: #C900FFA6;">AngularJS development halted in 2018</mark> with the final release of version 1.7.9.  

<mark style="background: #C900FFA6;">Angular (2+) was introduced in 2016</mark> as a complete rewrite of AngularJS, using TypeScript and following a component-based architecture.  

Angular introduced improved performance, server-side rendering, and a new dependency injection system.  

<mark style="background: #C900FFA6;">Angular has continued to evolve with frequent releases</mark>, including Angular 8 in 2019 and Angular 12 in 2021.  

Angular is one of the most popular front-end JavaScript frameworks used by companies such as Google, Microsoft, and IBM.

### <mark style="background: #C900FFA6;">Advantages of angular</mark>

<mark style="background: #C900FFA6;">Robust framework:</mark> Angular is a complete framework that provides a wide range of features for building large-scale applications.  

<mark style="background: #C900FFA6;">Declarative programming:</mark> Angular uses a declarative programming model that makes it easier to reason about your code and can improve the overall maintainability of your application.  

<mark style="background: #C900FFA6;">Strong typing:</mark> Angular is built using TypeScript, which provides strong typing and helps catch errors at compile time rather than run time.  

<mark style="background: #C900FFA6;">Dependency injection:</mark> Angular has a built-in dependency injection system that allows you to manage and reuse components throughout your application quickly.  

<mark style="background: #C900FFA6;">Large and active community:</mark> Angular has a large and active developer community, which means many resources and libraries are available to support development.  

<mark style="background: #C900FFA6;">Good tooling:</mark> Angular has a powerful CLI tool that helps streamline the development process by providing code generation and testing features.

### <mark style="background: #C900FFA6;">Disadvantages of angular</mark>

<mark style="background: #C900FFA6;">Steep learning curve:</mark> Angular has a relatively steep learning curve, especially for developers new to the framework or in front-end development.  

<mark style="background: #C900FFA6;">Opinionated:</mark> Angular is an opinionated framework that can be less flexible than other options, which may make it less suitable for some use cases.  

<mark style="background: #C900FFA6;">Large file sizes:</mark> Depending on how it's used, Angular can lead to larger file sizes and slower load times, which can disadvantage performance-sensitive applications.  

<mark style="background: #C900FFA6;">Complexity:</mark> Angular's many features and options can increase complexity, making it more challenging to build and maintain large applications.  

<mark style="background: #C900FFA6;">Upgrade path:</mark> Upgrading to a new version of Angular can be challenging due to changes in the framework's architecture and API, which can disadvantage some  
development teams.
