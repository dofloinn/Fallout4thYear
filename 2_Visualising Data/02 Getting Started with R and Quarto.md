### <mark style="background: #04FF00A6;">How Visualisations are Built</mark>  

<mark style="background: #04FF00A6;">At its most basic we need to decide?</mark>
- What data are we showing?  
- What visual properties represent that data?  
- How are those properties best drawn and arranged?

<mark style="background: #04FF00A6;">Humans perceive data through visual channels, such as:</mark>
- Position  
- Length  
- Size  
- Colour  
- Shape  
- Orientation  

A visualisation maps data variables to these perceptual channels.
